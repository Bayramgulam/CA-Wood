# CA Wood — dizayn planı

**Vizual dil:** tünd espresso fonunda isti bal rəngli işıq; krem fonlu, sakit redaktə üslubunda kataloq. Palitra: Espresso `#1B130E`, Qoz `#5A3A22`, Bal `#C88A3D`, Krem `#F4ECE0`.

**Tipoqrafiya:** Playfair Display (başlıqlar) + Manrope (mətn). Hər ikisi Azərbaycan əlifbasını dəstəkləyir.

**Axın:** sticky header → tam ekran hero → kateqoriya hərəkətli zolağı → üfüqi kateqoriya kartları → filtrli kataloq → B2B çağırışı → üstünlüklər → Instagram → əlaqə və footer.

**Hərəkət:** səhifə açılarkən hero başlığı maskadan görünür; skrollda başlıq və kartlar yüngül opacity/transform ilə ortaya çıxır; kateqoriya zolağı mobil swipe, masaüstündə üfüqi pinned keçid hissi yaradır. `prefers-reduced-motion` olduqda bütün animasiyalar dayandırılır.
